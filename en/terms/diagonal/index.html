📐Diagonal Run

ダイアゴナルラン

Diagonal Run — A run cutting across the pitch on the diagonal.

🇯🇵 この用語を日本語で読む：ダイアゴナルラン →

1💬 In a nutshell

“Run at an angle to vanish from the marker's field of view — like magic.”

2🎬 See it move

An original tactics board (blue = the team in focus, red = the opponent; attacking left to right). The board animates on its own.

⚽ Open the interactive version (117 more terms, each with its own board)

3🔍 Why it matters — what to watch for

Straight vertical runs stay in a defender's sight, but a diagonal one forces a hand-off of “who tracks him?” That split-second confusion frees a man. The best in the box all run at angles.

Columns put it“The winger's diagonal run drags the CB and empties the centre, where the No.8 arrives late.”
