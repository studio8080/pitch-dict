📐ダイアゴナルラン

Diagonal Run読み：だいあごなるらん

ダイアゴナルランとは、ピッチを斜め（対角線）に横切る走り込み。

🇬🇧 Read this term in English: Diagonal Run →

1💬 一言でいうと

「ナナメに走って、マークの“視界”から消える魔法」

2🎬 図で見る（動きます）

オリジナルの戦術ボードで図解（青＝注目チーム／赤＝相手、攻撃方向は左→右）。ボードは自動で動きます。

⚽ アプリ版で拡大して見る（他の117語もタップで図解）

3🔍 なぜ大事？ — ここに注目すると面白い

縦一直線の動きはDFの視界に収まったままですが、斜めの動きは「誰が付いていくか」の受け渡しを強制的に発生させます。その一瞬の混乱がフリーを生む。ゴール前の名手はみんな斜めに走っています。

コラムではこう書かれる「WGのダイアゴナルランがCBを引き連れて中央を空け、そこにIHが遅れて飛び込む設計だ」
